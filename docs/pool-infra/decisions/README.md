# Pool Infra Engineering Decision Records

Decision records preserve engineering context that should survive beyond the
conversation or development session in which a decision was made.

Suggested filename:

    ADR-NNN-short-description.md

## Suggested template

# ADR-NNN: Title

## Status

Proposed | Accepted | Superseded

## Context

Describe the problem and relevant upstream/Pool Infra behavior.

## Evidence

Record the observations, source analysis, runtime results, protocol behavior,
or other evidence that materially informed the decision.

## Alternatives considered

Document meaningful alternatives, including approaches tested or rejected.

## Decision

State the selected design or policy precisely.

## Rationale

Explain why the selected approach was preferred.

## Consequences

Record benefits, tradeoffs, operational implications, compatibility effects,
and maintenance obligations.

## Reassessment conditions

Describe what should cause this decision to be reconsidered, particularly
changes in future upstream releases.

## Related changes

Reference applicable Pool Infra change records.
